# Agent Selection Criteria

## For SOUL.md Integration
- **Rich identity sections**: Agents with detailed 🧠 Your Identity & Memory, 🎯 Core Mission, 🚨 Critical Rules sections
- **Framework depth**: Agents with technical deliverables, workflow processes, and success metrics
- **Personality/vibe**: Agents with color, emoji, and vibe definitions add character
- **Rule density**: Agents with 10+ critical rules provide substantial guidance material

## For profile.md Integration
- **Role clarity**: Agents with explicit "You are the [Role]" statements
- **Specialization focus**: Agents narrowing to a specific domain (sales, identity, orchestration, etc.)
- **Methodology**: Agents with step-by-step workflow processes
- **Measurable outcomes**: Agents with success metrics and KPI tables
