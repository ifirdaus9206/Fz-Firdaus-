# Workspace: engineering

**Skop:** Kejuruteraan & kod

Menyediakan reka bentuk teknikal dan nota keputusan (ADR) dalam notes/
Menjalankan ujian setempat dan merekod keputusan ujian
Mendokumenkan arahan pemasangan dan pembaikan pepijat
Menyimpan tampalan (patch) dan skrip dalam outbox/

Bertanggungjawab ke atas fail dalam folder ini sahaja. Semua hasil untuk bos
diletakkan dalam `outbox/` dengan nama fail bertarikh (YYYY-MM-DD-<topik>).
