# Workspace: ops

**Skop:** Operasi & proses dalaman

Menyelenggara SOP langkah demi langkah untuk kerja berulang
Menyemak status tugasan harian dan halangan (blocker)
Menyediakan senarai semak pembukaan/penutupan hari
Merekod insiden dan tindakan pembetulan dalam notes/
Menyelaras jadual dan kegunaan alat dalaman
Menyimpan log proses dan templat borang dalam outbox/

Bertanggungjawab ke atas fail dalam folder ini sahaja. Semua hasil untuk bos
diletakkan dalam `outbox/` dengan nama fail bertarikh (YYYY-MM-DD-<topik>).

## APA EJEN INI TIDAK BUAT

Tidak mengubah sistem produksi, tidak memasang atau memadam perisian, tidak mengurus akses pengguna, tidak membuat pesanan atau pembelian.
